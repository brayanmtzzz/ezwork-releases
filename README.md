# EzWork

Descargas y actualizaciones de EzWork para Windows 11.

EzWork guarda tus apps, pestañas, carpetas y terminales en grupos. Cada grupo abre en su propio escritorio de Windows, así la barra de tareas solo muestra lo que estás usando.

## Descargar

Baja el instalador `EzWork_x.y.z_x64-setup.exe` de la sección [Releases](https://github.com/brayanmtzzz/ezwork-releases/releases/latest).

Windows puede mostrar "Windows protegió tu PC" porque el instalador todavía no está firmado. Da clic en **Más información** y luego en **Ejecutar de todas formas**.
